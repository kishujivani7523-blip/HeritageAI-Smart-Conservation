# HeritageAI – Smart Heritage Conservation Platform

## Project Title

Smart Heritage Conservation Platform for Ahmedabad's Walled City & Modhera

## Domain

Tourism & Heritage

## Overview

HeritageAI is an Agentic AI-based smart conservation platform designed for Ahmedabad's Walled City and Modhera Sun Temple.

The platform combines multiple specialized AI agents to support heritage conservation, visitor management, cultural storytelling, encroachment detection, and conservation reporting.

## Problem Statement

Gujarat's UNESCO heritage sites, including Ahmedabad's Walled City and Modhera Sun Temple, face conservation risks from urban encroachment, weathering, unmanaged tourist footfall, and underutilized digital storytelling.

## Solution

HeritageAI uses five specialized Agentic AI modules:

1. Structural Health Monitoring Agent
2. Visitor Flow Management Agent
3. Personalized Heritage Storytelling Agent
4. Encroachment Detection Agent
5. Conservation Reporting Agent
